# شركة المبادلة الصناعية

موقع عربي RTL لشركة المبادلة الصناعية، بهوية كحلي وأزرق كهربائي وبرتقالي.

## تحديث الواجهة
- تطوير الخط في الشريط العلوي إلى Tajawal بوزن ثقيل مع توهج نيون أزرق وبرتقالي وخط ضوئي متحرك.
- استبدال الرموز النصية/الإيموجي في بطاقات المميزات بأيقونات SVG خطية متناسقة: الدعم الفني، الشراكات، الجودة، الالتزام بالمواعيد، تنوع المنتجات، والإنتاج الصناعي.
- استبدال إيموجي الدعم الفني بأيقونة سماعة SVG.
- الحفاظ على وظائف الموقع الحالية وتصميمه المتجاوب.

## التشغيل
افتح `index.html` في المتصفح أو ارفع محتويات المجلد إلى الاستضافة مع الحفاظ على مجلد `assets`.
